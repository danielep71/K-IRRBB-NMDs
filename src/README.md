# Production VBA source

Source-first application profile, adapted from VBA-SACCR-Toolkit.

- `core/`: host-independent numerical, econometric and validation functions (`CORE_*`, `Option Private Module`). `tools/check_source.py` rejects Excel object-model and UI identifiers here.
- `modules/`: explicitly supported public facade (`IRRBB_*`), listed in [`docs/PUBLIC_API.txt`](../docs/PUBLIC_API.txt). `IRRBB_Import` imports the two data files (read only) and returns totals, per-period outcomes, findings, warnings and lineage as tables.
- `workbook/`: host adapters (`WB_Import` runs the import from `Config` into `DataSummary`), the Excel document modules (`ThisWorkbook.cls` and one `sh<Sheet>.cls` per template sheet, imported by `tools/Sync-IRRBB-VBA.ps1` and embedded by the development-workbook builder) and the macro-free template `IRRBB_Template.xlsx` (generated by `tools/workbook/build_template.py`; never edited in Excel; layout in [`docs/WORKBOOK_CONTRACT.md`](../docs/WORKBOOK_CONTRACT.md)).
- `classes/`, `forms/`: introduce only when needed.

`core/` holds the first modules: `CORE_Parse` (locale-independent dates, decimals and rates of the data contract), `CORE_Codes` (segment codes, the currency allowlist and identifiers), `CORE_Sha256` (the SHA-256 data fingerprint) and `CORE_Import` (line-by-line validation of the account panel and market rates, warnings, totals, missing extracts, transition outcomes and the point-in-time view at a forecast origin; the caller supplies the lines, #71). No model and no public facade exist yet. Layout, dependency direction and the parameter and units boundary are defined in [`docs/REPOSITORY_STRUCTURE.md`](../docs/REPOSITORY_STRUCTURE.md).
