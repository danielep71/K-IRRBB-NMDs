# Examples

Only small, synthetic and redistributable examples.

- `modules/EX_DecayExample.bas` — fits the decay model, applies the `REG-1` overlay and scores the test window through `IRRBB_Decay` only, on a synthetic series read from a sheet named `DecayExample`. The template-based development workbook does not have that sheet yet (#36).

Each future example will identify its model version, input conventions, expected outputs and how to reproduce them using supported APIs.
