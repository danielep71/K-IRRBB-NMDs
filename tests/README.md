# Tests

Synthetic fixtures, reviewed expected values and the Excel regression harness live here. Group cases by model (Rates, Stable, Decay), transformation, validation and application recovery. Distinguish static checks from execution in real Excel.

`modules/` holds the VBA harness (#8). `TEST_Harness.RunTests` runs every case in the [register](../docs/methodology/TEST_CASES.md#register), in register order, and writes one row per case and one per assertion to the `Checks` sheet. A case is `PASS` only when it made at least one assertion and all passed; an unexpected error is `ERROR`; a registered case without a VBA implementation is `NOT RUN`, never `PASS`. Earlier results are cleared before a run starts; if writing the results fails, the status is `FAILED` with the primary and the cleanup error (`TEST_RunTestsWithWriteFault` forces that path). `TEST_RunTestsWithInjectedFailures` adds one failing assertion to `HARN-OUT-01` and raises an unexpected error in `DATA-CODES-01`, so a run can be shown to end `COMPLETE - FAILURES` with those cases `FAIL` and `ERROR`; `tools/devbuild/lo_smoke.py` runs both. `TEST_CoreCases` implements `HARN-OUT-01`, `DATA-PARSE-01`, `DATA-PARSE-02` and `DATA-CODES-01`; `TEST_WorkbookCases` implements `WB-LAYOUT-01`, which reads the workbook's sheets, CodeNames and names through Excel; `TEST_HashCases` implements `DATA-SHA-01`, the SHA-256 fingerprint against published and boundary vectors; `TEST_ImportCases` implements `DATA-IMPORT-01`, the import from temporary files through `WB_ImportData` to `DataSummary`, restoring the settings afterwards; `TEST_DataCases` implements `DATA-VALID-01`, `DATA-INVALID-01`, `DATA-PIT-01` and `DATA-PIT-02` against `CORE_Import`, with the fixtures and hand-computed expectations from `TEST_Fixtures`, a module generated by `tools/devbuild/fixture_module.py` (never edited by hand). Their expected values are literals that `tools/test_vba_harness.py` re-derives from the data contract and the template generator without Excel, and it keeps the harness registry equal to the register. Build the workbook to run it with `tools/devbuild/build_dev_workbook.py`.

Decay cases: fixtures and their generator in `fixtures/decay/`; independent expected values (numpy, scipy) with provenance in `expected/decay/`, produced by `expected/decay/make_expected.py`, which also regenerates `modules/TEST_DecayData.bas` (`--emit-vba`; never edit it by hand). `modules/TEST_DecayCases.bas` implements the cases; `tools/test_vba_harness.py` checks that the generated module equals the expected files.

Synthetic fixtures for the data contract are in `fixtures/data_contract/`, with hand-computed expectations in `expected/data_contract/`; `tools/test_data_contract.py` keeps them consistent with [`docs/methodology/DATA_CONTRACT.md`](../docs/methodology/DATA_CONTRACT.md).
