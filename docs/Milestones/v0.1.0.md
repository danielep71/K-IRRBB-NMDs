## 🎯 Objective

Lay the foundation for K-IRRBB, a source-first Excel/VBA application for
IRRBB behavioral models: architecture and source boundaries, baseline host,
data and model contracts, static quality gates, synthetic-data and IP
safeguards, issue governance and the Excel evidence protocol.

**Why it matters.** A numerically plausible model is difficult to verify if
its data, units, authoritative source or tested version are unclear. The
foundation makes these decisions explicit and separates calculations, Excel
integration and the public interface, so that a worksheet or import problem
can be distinguished from an econometric one and each correction traced.

## 📦 Scope

- Decide the application profile and source architecture: host-independent
  `src/core`, public facade and workbook adapters, canonical units and
  immutable parameter sets (#2; [Repository structure](../REPOSITORY_STRUCTURE.md)).
- Define the supported hosts: Windows 64-bit Excel target, 32-bit best
  effort, four default references, no runtime dependencies (#3;
  [Installation](../../INSTALLATION.md#supported-hosts),
  [Excel evidence](../EXCEL_EVIDENCE.md)).
- Specify the data contract: account panel and market-rate schema, segments,
  error and warning codes `E01`–`E11` / `W01`–`W06`, all-or-nothing import,
  lineage and synthetic fixtures (#4; [Data contract](../methodology/DATA_CONTRACT.md)).
- Establish the model contracts and independent validation criteria: rate
  pass-through (ECM), stable amount (fractional logit), decay (MPA),
  regulatory overlay kept separate from the fit (#9;
  [Model contracts](../methodology/MODEL_CONTRACTS.md),
  [Sources](../methodology/SOURCES.md), [Test cases](../methodology/TEST_CASES.md)).
- Build portable static gates and CI, including core-boundary and COM checks,
  and correct the audit findings (#7, #22, #25; [Tooling](../../tools/README.md)).
- Set up issue forms, labels, priorities and milestone automation (#10;
  [Governance](../GOVERNANCE.md)).
- Adopt synthetic-data, confidentiality and third-party IP safeguards, with a
  full-history scan (#11;
  [Contributing](../../CONTRIBUTING.md#data-confidentiality-and-provenance)).
- Document the build, Excel evidence and release gates and the PR-only
  integration process (#12; [Releasing](../../RELEASING.md)).
- Record the distribution review and public visibility (#42;
  [Governance](../GOVERNANCE.md#licensing-and-distribution)), and relicense
  under the Mozilla Public License 2.0 (#49; [LICENSE](../../LICENSE)).

Exported VBA is the authoritative source; any executable workbook must be
built from it. The evidence protocol distinguishes static inspection, Excel
compilation, test execution and independent numerical verification.

## 🏁 Exit criteria

- [x] Architecture, host, data and model contracts are accepted and
  documented, linked to their acceptance evidence (#2, #3, #4, #9).
- [x] Ten portable static gates run locally and in CI; core code cannot reach
  the Excel object model or COM automation.
- [x] Issue forms, labels, priorities and milestone automation enforce one
  owner, one milestone and one priority per issue; the automation default
  `ISSUE_MILESTONE_NUMBER` was set to v0.2.0 before this milestone was retired.
- [x] Synthetic-data and IP safeguards are in force, and the full history has
  been scanned.
- [x] The Excel evidence protocol and release gates are documented; static CI
  is never presented as Excel evidence.
- [x] Public visibility is approved and the repository is licensed under
  MPL-2.0.
- [x] Remaining work is complete or explicitly reassigned with its
  acceptance requirements; closeout was accepted on 2026-10-09
  ([foundation closeout](../FOUNDATION_CLOSEOUT.md)).

**Example acceptance case.** A developer can determine where to add a
mathematical function, which inputs it receives, how to expose it to the
application and which evidence belongs in the PR, and understands that a
passing Python check does not establish that the function compiles or
produces correct results in Excel.

## 🚫 Not in scope

VBA source, a workbook, any econometric model or validated result. Static CI
does not compile or run VBA, and defining the evidence protocol is not the
same as executing it.
